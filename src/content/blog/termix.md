Полный контроль над серверами без подписок и ограничений! Termix — это мощная self-hosted платформа с веб-интерфейсом для управления серверами. Это полностью бесплатная и open-source альтернатива Termius.

### Почему Termix круче облачных аналогов:

- **Полностью бесплатно навсегда.** Никаких ограничений по функциям в платной подписке.
- **Твои данные только у тебя.** Серверная часть шифруется (Encrypted SQLite), а версия Desktop может работать вообще без бэкенда Termix.
- **Огромный охват устройств.** Docker, AUR, Flatpak, iOS/Android, Mac App Store, Chocolatey — можно зайти с чего угодно.
- **Визуализация Homelab.** Встроенный граф сети для отображения статуса ваших железок.

### Что умеет:

- 💻 SSH, RDP, VNC — доступ к терминалу и удаленному рабочему столу прямо в браузере.
- 📂 Файловый менеджер — редактируй файлы на сервере с sudo-правами.
- 🔒 SSH-туннели — проброс портов с авто-переподключением и мониторингом.
- 🐳 Docker — управление контейнерами (старт, стоп, логи).
- 📊 Мониторинг — графики CPU, памяти и диска на дашборде.

Установка за минуту через Docker Compose (ссылка в описании).
Кроссплатформенность: веб, приложения для Windows, Linux, macOS, iOS и Android.
